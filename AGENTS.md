# Repository Agent Instructions

The canonical project-wide instructions are in
`.github/copilot-instructions.md`. Read and follow that file before changing
code, scripts, tests, or documentation in this repository.

Reusable task prompts are stored in `.github/prompts/*.prompt.md`. Inspect that
directory and read the prompt that matches the current task when one applies.
These are task templates, not additional project-wide rules, so do not apply
unrelated prompts to every task.

Keep the Copilot instruction and prompt files in their existing `.github`
locations. Do not copy their contents into this file or create tool-specific
duplicates; update the canonical file instead.
